# Resource Survival Simulator

A turn-based Python survival/resource-management game where the player manages food, water, and energy while making decisions to survive as many days as possible.

## Features

- Food, water and energy management
- Multiple player actions
- Day-by-day survival system
- Game-over conditions
- Player action tracking
- Survival statistics

## How to Run

Run `survival.py` using Python:

```bash
python survival.py
